═══════════════════════════════════════════════════════════════════════════════
                            RECOMMENDATION ALGORITHM
═══════════════════════════════════════════════════════════════════════════════

Final Score = (ML_Score × 0.4) + (Tag_Match × 0.25) + (Popularity × 0.15) + (Rating × 0.2)

Components:
  1. ML Score (40%)        - From Python engine based on emotion
  2. Tag Match (25%)       - Jaccard similarity with preferences
  3. Popularity (15%)      - Based on enrollment count
  4. Rating (20%)          - Based on course ratings

Example:
  User emotion: MOTIVAT
  Preferred tags: ["Machine Learning", "Python"]
  
  → ML engine returns: "Advanced Deep Learning" with 92.5% score
  → Tag matching: 88% (has ML and Python tags)
  → Popularity: 75% (2000 enrollments)
  → Rating: 90% (4.5/5 stars)
  
  Final Score: (92.5 × 0.4) + (88 × 0.25) + (75 × 0.15) + (90 × 0.2)
             = 37 + 22 + 11.25 + 18
             = 88.25% → Highly recommended!
