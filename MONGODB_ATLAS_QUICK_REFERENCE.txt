   • Stores: User data, preferences, mood history
   • Indexes: user_id, current_mood, last_active

courses
   • Stores: Course information, metadata, ratings
   • Indexes: id, category, tags, rating

recommendations_cache
   • Stores: Cached recommendations (24h TTL)
   • Indexes: user_id, created_at

user_interactions
   • Stores: User activity logs (enrollments, completions)
   • Indexes: user_id, course_id, timestamp

  → Verify .env.ml exists

  → Check internet connection

API Won't Start?
  → Run: python verify_mongodb.py
  → Check port 5000 is available
  → Verify Flask is installed

  → Check connection: python verify_mongodb.py
  → Check request body format
  → Look at API logs for details
