# MongoDB Image Upload - Quick Reference

## 🎯 What This Does

**Before:** Images from Unsplash URLs
```
Course → thumbnail: "https://images.unsplash.com/..." → External Load → Blurry/Slow
```

**After:** Images from MongoDB Atlas
```
Course → thumbnail: "unsplash..." (fallback)
      → thumbnailImageId: "507f1f77bcf86cd..." (MongoDB) → Local Cache → Sharp/Fast
```

---

## 📁 Files You'll Use

### Upload a Course Thumbnail:
1. Open `http://localhost:5173`
2. **Admin Panel** → **Gestionare Imagini** → **Thumbnail-uri Cursuri**
3. Click **[Încarcă Imagine]** button
4. Select image from file explorer
5. Wait for upload → See checkmark ✓

### Upload a Reel Thumbnail:
Same as above, but select **Thumbnail-uri Reels** instead

## 🔄 Behind the Scenes

```
Frontend (React)
  ↓
AdminPanel → imageUploadManager
  ↓
POST /api/admin/courses/:id/thumbnail
  ↓
Backend (Node.js)
  ↓
MongoDB GridFS (image stored)
  ↓
Course document gets thumbnailImageId
  ↓
Frontend shows: ✓ Stocata în MongoDB
```

## 📊 What Gets Stored Where

### MongoDB Collections:

```
courses {
  _id: "course-123",
  title: "React",
  thumbnail: "https://unsplash...",          ← Fallback
  thumbnailImageId: ObjectId("507f..."),    ← MongoDB Image ID
}

reels {
  _id: "reel-456",
  title: "Tips",
  thumbnail: "https://unsplash...",         ← Fallback
  thumbnailImageId: ObjectId("607f..."),    ← MongoDB Image ID
}
```

### MongoDB GridFS Buckets:

```
thumbnails (course images)
  ├─ thumbnails.files     ← metadata
  └─ thumbnails.chunks    ← actual image data

reelThumbnails (reel images)
  ├─ reelThumbnails.files
  └─ reelThumbnails.chunks
```

### Browser IndexedDB:

```
StreamclassMedia {
  course-thumbnail-{courseId}  ← cached 7 days
  reel-thumbnail-{reelId}      ← cached 7 days
}
```

## 🔌 API Endpoints (Backend)

### Upload Endpoints:
```
POST /api/admin/courses/:courseId/thumbnail
  Input: FormData { thumbnail: File }
  Output: { imageId: "507f...", success: true }
  Auth: Required

POST /api/admin/reels/:reelId/thumbnail
  Input: FormData { thumbnail: File }
  Output: { imageId: "607f...", success: true }
  Auth: Required
```

### Display Endpoints:
```
GET /api/media/thumbnails/:imageId
  Output: Binary image (JPEG/PNG)
  Cache: 7 days
  Auth: None needed

GET /api/media/reel-thumbnails/:imageId
  Output: Binary image (JPEG/PNG)
  Cache: 7 days
  Auth: None needed
```

## 🚨 Important Notes

1. **Without Backend**: Frontend won't upload (endpoints return 404)
2. **File Limits**: Max 5MB per image
3. **Auto-Cache**: Images cached 7 days locally
4. **Fallback**: If no MongoDB imageId, uses external URL
5. **Offline**: Cached images work without internet
