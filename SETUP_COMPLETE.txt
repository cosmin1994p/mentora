═════════════════════════════════════════════════════════════════════════════════
🎓 ALGORITHM OVERVIEW
═════════════════════════════════════════════════════════════════════════════════

The recommendation engine uses a HYBRID APPROACH:

1. CONTENT-BASED FILTERING
   • Maps user mood to course categories & tags
   • Matches course difficulty to user's mood state
   • Considers user's learning history
   • Calculates content similarity to previous courses

2. COLLABORATIVE FILTERING (Implicit)
   • Uses course ratings from all users
   • Considers popular courses (social proof)
   • Learns from completion patterns

3. POPULARITY-BASED RANKING
   • Weights by student count
   • Weights by course rating
   • Encourages discovery of trending courses

Result: Each course gets a 0.0-1.0 score (displayed as 0-100%)
        Courses ranked by final score and top N returned

    "enrolledCourses": [],
    "completedCourses": [],
